📖 教程：如何下载和使用别人的 Skill

Skill（技能包） 是 AI Agent 的「专业知识模块」。别人写好并分享的 Skill，你可以下载安装到自己的 Agent 里，让它瞬间获得新能力——比如自动部署、生成测试、对接数据库等。以下是通用流程：

1

找到 Skill 市场或仓库

大多数 AI 编码工具都有官方的 Skill/MCP 市场：

• Claude Code： /plugin marketplace 或访问 GitHub 上的 awesome-claude-code
• Codex： 内置插件商店，在 Codex 设置 → Plugins 中浏览
• Cursor/Windsurf： 扩展市场搜索相应插件
• GitHub： 搜索 claude-code-plugin 或 codex-skill

2

下载 / 安装 Skill

以 Claude Code 为例，安装官方市场中的 Skill：

# 在 Claude Code 对话中输入 /plugin install @anthropic/agent-browser # 或从 GitHub 直接安装 /plugin install github:username/skill-repo

以 Codex 为例：

# Codex 设置 → Plugins → 搜索 → Install # 或手动：将 Skill 文件夹放到项目根目录的 .codex/skills/ 下 mkdir -p .codex/skills/my-skill # skill 配置自动生效
3

配置和启用

安装后通常需要在配置文件中声明：

# CLAUDE.md（Claude Code） ## Skills - /deploy — 自动部署到 Vercel - /test — 运行测试套件 # AGENTS.md（Codex / 通用） ## Skills - code-review — PR 审查助手
4

验证 Skill 是否生效

安装后在 Agent 对话中直接调用：

# Claude Code /deploy # Codex @skill deploy

如果 Skill 有自动触发条件（Hook），它在满足条件时自动执行，无需手动调用。

💡 提示：Skill 本质是一个包含指令文件和脚本的文件夹。手动安装只需把它放到 Agent 的 skills 目录下。大部分开源 Skill 在 GitHub 上可以找到——搜索关键词「claude-code-skill」「codex-plugin」即可。
